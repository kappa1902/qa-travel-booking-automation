# Курсовой проект: Автоматизация тестирования сервиса покупки туров «Путешествие дня»

Данный проект содержит комплекс автотестов для проверки UI и API функциональности веб-сервиса покупки туров, интегрированного с СУБД (MySQL) и эмулятором банковских сервисов.

---

## 🛠 Технологии и требования

* **Python 3.10+**
* **Pytest** (фреймворк для тестирования)
* **Selenium WebDriver** (UI-автоматизация)
* **PyMySQL** (взаимодействие с базой данных)
* **Docker & Docker Compose** (контейнеризация СУБД)
* **Allure Framework** (генерация визуальных отчетов)

---

> ## 🚀 Инструкция по запуску
>
> ### 1. Подготовка окружения
> Убедитесь, что активировано виртуальное окружение и установлены зависимости:
>
> ```powershell
> python -m venv .venv
> .\.venv\Scripts\activate
> pip install -r requirements.txt
> ```
>
> ### 2. Запуск СУБД
> Перед запуском убедитесь, что Docker Desktop запущен, и выполните команду:
>
> ```powershell
> docker-compose up -d
> ```
>
> ### 3. Запуск тестируемого приложения (SUT) 
> Запустите `aqa-shop.jar` с указанием URL подключения к MySQL:
>
> ```powershell
> java -Dspring.datasource.url=jdbc:mysql://localhost:3307/app -jar aqa-shop.jar
> ```
>
> ### 4. Запуск автотестов 
> Запустите тестовый набор с сохранением результатов для Allure:
>
> ```powershell
> pytest tests/ --alluredir=allure-results
> ```
>
> ### 5. Генерация и просмотр отчетов Allure
>
> Для просмотра отчета через локальный веб-сервер:
>
> ```powershell
> allure serve allure-results
> ```
>
> Для формирования статического HTML-отчета в папке проекта:
>
> ```powershell
> allure generate allure-results -o allure-report --clean
> ```

## 📊 Покрытые сценарии 

* **API-тесты (`tests/test_api.py`):**
  * Покупка по карте со статусом `APPROVED` через `/api/v1/pay`.
  * Покупка по карте со статусом `DECLINED` через `/api/v1/pay`.
  * Оформление кредита по карте со статусом `APPROVED` через `/api/v1/credit`.
  * Оформление кредита по карте со статусом `DECLINED` через `/api/v1/credit`.
  * Валидация структуры ответа JSON и записей в базе данных.

* **UI-тесты (`tests/test_ui.py`):**
  * Позитивный сценарий покупки по картам со статусом `APPROVED`.
  * Позитивный сценарий покупки в кредит по картам со статусом `APPROVED`.
  * Негативный сценарий обработки карты со статусом `DECLINED` (маркирован `@pytest.mark.xfail` из-за обнаруженного бага).
  * Проверка валидации полей при отправке пустой формы.
